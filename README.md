# NewComers Studio — сайт

Многостраничный статический сайт для студии перевода и озвучивания
[NewComers Studio](https://vk.com/newcomers_studio). Тёмная золотая тема,
крупное левое меню, скруглённый фирменный стиль.

## Структура страниц

- `index.html` — главная (hero, тизер «о студии», топ проектов, новости, контакты)
- `about.html` — о студии (история, роли в команде)
- `services.html` — услуги и этапы работы
- `library.html` — библиотека работ: топ-12 проектов карточками + полный каталог
  (150+ сериалов, фильмов, аниме) с поиском и фильтром по категориям
- `project.html?slug=...` — карточка одной работы (постер, описание, ссылка на
  трейлер, блок «над проектом работали»); открывается по клику на любую позицию
  библиотеки
- `prices.html` — цены (индивидуальный подход)
- `news.html` — новости
- `contacts.html` — контакты и соцсети

## Файлы

- `css/styles.css` — стили (тёмная тема, золотой акцент, левый сайдбар)
- `js/main.js` — переключение мобильного меню, появление блоков при скролле,
  поиск/фильтр и рендер библиотеки
- `js/library-data.js` — данные каталога (используются на `library.html` и
  `project.html`); 12 записей помечены `featured: true` и содержат
  индивидуальные `badge`/`posterClass`/`description`, остальные используют
  общий шаблон карточки
- `assets/favicon.svg` — иконка вкладки (тот же скруглённый герб NC)

## Локальный просмотр

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и перейти на `http://localhost:8000`.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
2. Воркфлоу `.github/workflows/deploy.yml` соберёт и опубликует сайт при пуше в
   ветку по умолчанию.

## Контент для обновления

- Реальные постеры вместо цветных заглушек (пришлите файлы — вставим напрямую
  в `assets/`, скачать чужие картинки из интернета среда не позволяет)
- Реальные ссылки на трейлеры конкретных проектов в `project.html` (сейчас
  ведут на канал YouTube целиком)
- Конкретный состав актёров/переводчиков по проектам — сейчас в карточке
  общая формулировка «команда NewComers Studio», без выдуманных имён
- Плейсхолдер в «Новости» — заменить на реальные посты по мере выхода
