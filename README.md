# NewComers Studio — сайт-визитка

Одностраничный статический сайт для студии перевода и озвучивания
[NewComers Studio](https://vk.com/newcomers_studio).

## Структура

- `index.html` — разметка страницы (шапка, hero, «О студии», «Проекты», «Контакты», подвал)
- `css/styles.css` — стили (тёмная тема, золотой акцент)
- `js/main.js` — шапка при скролле, мобильное меню, появление блоков при скролле
- `assets/favicon.svg` — иконка вкладки

## Локальный просмотр

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и перейти на `http://localhost:8000`.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
2. Воркфлоу `.github/workflows/deploy.yml` соберёт и опубликует сайт
   при пуше в `main`.

## Контент для обновления

- Реальные ссылки на трейлеры проектов в разделе «Проекты» (сейчас ведут на канал YouTube целиком)
- Актуальная статистика в разделе «О студии»
- При желании — постер-картинки вместо цветных заглушек в карточках проектов
