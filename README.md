# NewComers Studio — сайт

Многостраничный статический сайт для студии перевода и озвучивания
[NewComers Studio](https://vk.com/newcomers_studio).

## Структура страниц

- `index.html` — главная (hero, о студии, топ проектов, новости, контакты)
- `services.html` — услуги и этапы работы
- `library.html` — библиотека работ: топ проектов + полный каталог (150+ сериалов, фильмов, аниме) с поиском и фильтром по категориям
- `prices.html` — цены (индивидуальный подход)
- `news.html` — новости
- `contacts.html` — контакты и соцсети

## Файлы

- `css/styles.css` — стили (тёмная тема, золотой акцент)
- `js/main.js` — шапка при скролле, мобильное меню, появление блоков при скролле, поиск/фильтр библиотеки
- `assets/favicon.svg` — иконка вкладки

## Локальный просмотр

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и перейти на `http://localhost:8000`.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
2. Воркфлоу `.github/workflows/deploy.yml` соберёт и опубликует сайт при пуше в
   ветку по умолчанию.

## Контент для обновления

- Реальные ссылки на трейлеры конкретных проектов (сейчас ведут на канал YouTube целиком)
- Постер-картинки вместо цветных заглушек в карточках топ-проектов (при наличии — прислать файлы напрямую)
- Плейсхолдер в «Новости» — заменить на реальные посты по мере выхода
